# Historical Sentinel release assets

`sentinel-1.0.0/` preserves the original, unchanged Sentinel 1.0.0 web release
from the imported PR, including its checksums and attribution. These are
Sentinel binaries, not Cerberus Unchained builds. This directory is outside the
installer's public tree and is not selected by the Unchained installer.

Use the original Sentinel project and its installer for that firmware. Follow
`docs/UNCHAINED_BUILD.md` to build and package Unchained.
