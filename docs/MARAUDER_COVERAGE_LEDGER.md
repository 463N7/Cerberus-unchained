## Source and reproduction

The [inventory](MARAUDER_SOURCE_INVENTORY.json) is pinned to [511bb369](https://github.com/justcallmekoko/ESP32Marauder/tree/511bb3694d0c4dc064888e762bde44fcc9b7f48a); reviewed develop [79cc6bcb](https://github.com/justcallmekoko/ESP32Marauder/tree/79cc6bcba1db6679baee1dab2b0c1ad5010e6363) has the same source tree. [Baseline notes](MARAUDER_DEVELOP_BASELINE.md) explain that relationship. Numeric value 85 is shared by BT_SCAN_IBEACON and BT_FINDMY_SOUND, so symbols remain audit keys.

Edit [MARAUDER_COVERAGE_STATUS.json](MARAUDER_COVERAGE_STATUS.json), then run `python tools/build_marauder_coverage_ledger.py`. `--check` rejects stale output. No adjacent private workspace is needed. Optional `--upstream /path/to/ESP32Marauder` also verifies the clean pinned checkout and recorded source hashes.
